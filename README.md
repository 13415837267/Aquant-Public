# 个人量化交易系统（首版重构）

本仓库只负责增量数据维护、全市场收益标签研究、研究网页及云端发布。历史数据仍保存在原位置并继续增量维护。

## 新研究逻辑

T 日收盘因子 → T+1 开盘买入 → T+2 开盘卖出 → 扣除交易成本后分类为盈利、亏损、平盘。首先比较全部可用因子在三类样本上的差异，再用训练期挖掘可解释组合、验证期选阈值、最终留出期独立评估。

研究报告位于 data/research/latest_report.json。完整逐股逐日样本由 GitHub Actions 以工件方式提供。研究结果不自动替代个人策略，不会打开实盘或自动下单。

## 数据资产与采集

- 唯一运行分支：main。
- 保留原有数据获取脚本和 02 数据维护工作流。
- data/history/ 和 data/fundamentals/ 下的历史行情、估值及季度财务数据不随本次重构清理。
- 增量采集继续按北京时间运行，不重复下载已完成历史批次。

## 运行纪律

所有程序测试、研究与构建只在 GitHub Actions 云端执行。财务因子只允许使用信号日前已公告的数据；历史标签严格依赖 T+1/T+2 开盘价。正式发布和自动下单保持关闭。
