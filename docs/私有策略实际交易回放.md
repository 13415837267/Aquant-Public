# 私有策略实际交易回放

## 实验目的

本实验直接运行 Aquant-Private 的真实 score_universe 与 admit_candidates，比较冻结基准 2.6.0 与单一策略候选 2.7.0。它不训练新模型，不搜索新阈值，不改生产状态。

## 唯一策略改动

当 T 日市场中位收益至少 +1.0%，且个股收盘价距近 20 日最低价不超过 0.5% 时，实验版在原始模型分数上增加 1.0 分。精度概率、准入阈值、因子系数、市场准入、个股风控、每日候选上限及止盈止损参数保持不变。

## 同口径评估

- 验证窗口从 2023-01-03 开始，在 2025 年最终补充窗口前留足五个前瞻交易日。
- 最终补充窗口从 2025-01-02 至 2026-09-30，但必须留足完整的五日未来路径；它不是全新未见留出集。
- T 日只按收盘可见特征排序及准入。T+1 开盘价只用于执行可行性检验，不为无法买入的已选候选补位。
- 采用 T+1 开盘入场、T+2 起允许退出、最长持有五个交易日、同日止损优先、开盘跳空按更差可成交价处理、现金约束且不加杠杆。
- 比较往返成本 10、15、20 基点，并统一报告交易数、复利、平均单笔净收益、盈利因子和最大回撤。

## 预先固定的判定门槛

验证期至少 100 笔完成交易，补充期至少 40 笔；两窗口的三档成本均要求复利和平均单笔净收益为正、盈利因子不低于 1.2、最大回撤不差于 -15%。此外，实验版在两个窗口的三档成本下，复利不得低于基准，最大回撤不得比基准恶化超过 0.10 个百分点；至少一个情景复利必须严格高于基准。

任何条件未满足，结论为拒绝此次代码改动，不因测试成功或增加了候选数而保留。通过本实验也只代表历史研究候选，不能替代未来至少 60 个交易日的影子验证，不意味着正式发布或自动下单。

## 第二次失败的根因与修复（2026-10-17）

- 云端运行 `38946088192` 在“检查公开回放脚本与测试”步骤失败；基准版和实验版的测试及实际回放均被跳过，未生成策略结果。
- 日志显示，公开仓库步骤运行无路径限制的 `python -m pytest -q`，因此 pytest 除了公开仓库自身测试，还递归收集了同一工作目录下的 `baseline-strategy/tests` 和 `candidate-strategy/tests`。这些私有策略测试在公开仓库根目录上下文中导入 `strategy`，造成 `ModuleNotFoundError: No module named 'strategy'`。
- 最小修复：公开仓库质量检查改为 `python -m pytest -q tests`，只收集公开仓库自己的测试。基准策略与实验策略仍分别在各自工作目录运行 `python -m pytest -q`，确保两个私有版本独立验证，不跳过它们的测试。
- 本次只修复测试发现范围，不改变任何策略逻辑、参数、回测口径、正式生产状态或自动下单状态。修复是否有效以新的 GitHub Actions 运行实际完成为准。
