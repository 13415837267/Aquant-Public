# 04 历史研究流水线说明

本流水线只在 GitHub Actions 云端执行训练、历史研究和验证，不使用本地设备参与运行。

## 当前研究纪律

- 公开仓库与个人策略仓库均只使用 `main` 一个分支。
- 训练与验证统一遵守北京时间、T+1 开盘入场、T+2 起允许退出、最多持有 5 个交易日。
- 严格标签：先触发 -3% 止损即失败；只有在止损前达到净收益至少 1% 才算成功。
- 04 长任务按研究日期持久化，每 5 个研究日形成检查点，并持续写入进度日志。
- 研究门禁不得通过降低阈值或修改最终留出集来制造通过。
- 梯度提升模型属于独立研究实验；只有验证集和最终留出集均达到正式门禁，且完成审计后，才允许进入后续策略候选。

## 本次新增实验

`scripts/train_path_aware_gbdt.py` 使用历史训练区间建立路径感知梯度提升分类模型，在验证集选择阈值，再只评估一次最终留出集。实验结果以工作流产物保存，不自动修改正式策略。

## 下一轮单变量实验

在不改变严格标签、验证集、最终留出集、模型结构和正式门禁的前提下，增加“近期训练窗口”实验：仅把训练起点从 2015-01-05 改为 2019-01-02，其余参数保持不变。该实验用于检验市场状态漂移下缩短历史训练窗口是否改善 2023-2026 的泛化能力；结果仅作为研究依据，不自动进入生产。


## 60%以上研究试运行版

近期训练窗口实验最终留出在概率阈值 0.60 下取得 604,453 个样本、62.32% 胜率，威尔逊下界 62.20%，样本覆盖率 51.68%；验证集为 59.15%。该结果仅用于网页观察和模拟研究，正式生产门槛仍为 80%，不会因为试运行而解除生产门禁。

## 训练基准切换与候选池重建

本次基准切换以近期训练窗口模型作为当前候选池唯一研究基准：训练区间为 2019-01-02 至 2022-12-30，验证区间为 2023-01-03 至 2024-12-31，最终留出区间为 2025-01-02 至 2026-09-30。候选生成固定采用概率阈值 0.60，并从通过阈值的标的中取模型概率最高的 2 个；不再使用旧 2.5.0 的候选准入、覆盖回退或每日首选救援规则。

候选生成在 GitHub Actions 云端重新训练同一近期窗口模型后，对最新已完成交易日逐标的推理。候选、下一交易日计划和网页必须逐项继承同一快照；正式生产门禁仍保持 80%，当前版本只能用于研究/模拟。旧候选仅进入 candidates_history 作为历史审计，不参与当前候选生成。
