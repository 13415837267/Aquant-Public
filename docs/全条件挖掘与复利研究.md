# 全条件挖掘与可执行复利研究

## 研究范围

本研究只在 GitHub Actions 云端运行，与正式生产模型隔离。研究时间范围为 2015-01-05 至 2026-09-30，按训练集、验证集和最终留出集分开：在训练集发现条件，在验证集选择参数，最终留出集只用于最终检验。

## 条件与模型

- `scripts/path_rule_mining.py`：单因子与双条件组合挖掘。
- `scripts/path_regime_rule_mining.py`：市场状态分层及三条件组合挖掘。
- `scripts/strict_path_strategy_score_mining.py`：当前私有策略的评分阈值对比。
- `scripts/train_short_term_model.py`：净收益达到 1% 的短线模型。
- `scripts/train_executable_path_model.py`：净收益达到 3% 且遵守可卖出时序的路径模型。
- `scripts/run_all_conditions_research.py`：依序运行以上研究，记录阶段状态、时间、提交号、结果摘要和失败信息。

## 复利组合模拟

`scripts/compound_portfolio_backtest.py` 使用训练好的高精度模型，概率阈值只根据验证集确定，再冻结到最终留出集。模拟限制现金、不加杠杆，并过滤 T+1 开盘涨停与停牌标的；T+1 开盘买入，T+2 起最早退出，最长持有五个交易日。同一根日线同时触及止盈与止损时，按保守规则先计止损。往返成本按研究参数计入。

输出指标包括严格目标命中率、正收益率、累计收益、年化复利、最大回撤、夏普比率、平均单笔净收益、几何平均单笔收益和退出原因。每日排名 Top-K 作为独立对照，不能代替验证集冻结的概率阈值策略。

## 产物与恢复

- 复利模拟输出：`data/backtest/high_precision_compound_portfolio_latest.json`。
- 条件挖掘输出：`data/backtest/*_research_latest.json`。
- 阶段日志与进度清单：`data/research/all_conditions/` 和 `data/backtest/all_conditions_research_manifest_latest.json`。
- `scripts/research_checkpoint_runner.py` 为高精度研究、复利评估及两项路径感知模型实验提供跨运行检查点；阶段成功后马上保存检查点快照，不必等待整轮工作流结束。
- 检查点存储在GitHub Actions缓存中，恢复时按最近的检查点前缀查找；每个阶段完成后显式写入新的不可变缓存快照。缓存可能被平台清理，因此它是加速恢复层，不是永久归档。
- 复用之前必须同时校验研究日期、历史行情与股票范围数据指纹、依赖代码摘要、依赖版本、命令参数及结果文件摘要，并确认结果仍是有效JSON。任一项不匹配或文件缺失、损坏，就只重跑受影响阶段。
- 全条件挖掘采用阶段级指纹，不再把公开仓库当前提交号作为整轮唯一兼容条件；无关文档或恢复机制提交不会自动令全部研究失效。正式策略提交只会使依赖该私有策略的评分阶段失效。
- 阶段成功标记仅在命令成功且结果文件有效后原子写入；失败和中断记录进入北京时间审计日志。下一次运行仅复用与输入完全兼容且摘要一致的最近成功结果。

研究排序不只看胜率，还要同步比较样本量、Wilson 胜率置信下界、扣除成本的收益分布、复利增长、最大回撤和逐年稳定性。研究产物不得自动覆盖 `data/models/production_v1.json`，也不得降低正式质量门槛。


## 2026-10-09 失败修复记录

- 失败现象：单因子/双条件挖掘与市场状态/三条件挖掘在路径标签计算阶段报出“数组真假值不明确”。
- 根因：按交易日检查止损时，最低价误用了整只股票未来五日的最低价数组，没有使用当前日的单个最低价。
- 修复：两个脚本统一按 `lows[row, d]` 读取当日最低价；止损先于止盈判断的保守规则不变，且 T+1 仍不允许卖出。
- 回归验证：新增合成行情测试，覆盖 T+1 触及止损但不可卖出、T+2 止盈，以及同日止盈止损冲突时止损优先。
- 工作流：直接修改相关研究脚本会触发云端研究；汇总产物将收录条件、模型、复利模拟结果及阶段清单，失败时仍尽量保留成功阶段的证据。


## 2026-10-09 断点续传加固记录

- 研究阶段增加跨运行检查点执行器，分别验证脚本及依赖文件摘要、命令参数、Python版本、依赖清单、历史行情和股票范围数据指纹、输入文件摘要与结果文件摘要。
- 模型研究工作流在高精度研究、复利评估、全条件挖掘的五个子阶段及路径感知模型阶段后分别保存云端检查点快照；全条件子阶段拆分为独立步骤，即使中途超时也能从最近成功子阶段继续。新运行启动时恢复最近快照，再对每个阶段独立做兼容性校验。
- 全条件阶段清单升级为第2版：不再因为公开仓库提交号变化而整体失效；私有策略提交变化仅触发依赖私有策略的评分阶段重新执行。
- 新增云端测试覆盖指纹稳定性、输入变化识别、结果摘要异常识别及无成功标记时拒绝复用。完整行为以GitHub Actions语法检查、测试结果及下一轮实际恢复日志为最终依据。

- 补充说明：阶段总清单独立写入 `data/backtest/all_conditions_research_manifest_latest.json`；编排器不再回写高精度模型结果文件，避免研究状态更新改变模型输出摘要，导致下一轮误判检查点损坏。


## 2026-10-10 退出规则诊断实验

- 基线回测发现最终留出集累计复利收益为负，且最大回撤明显；因此新增纯研究用途的止盈/止损参数敏感性实验，不改变模型特征、信号阈值或正式生产策略。
- 仅在验证集对净止盈目标 1.0%、1.5%、2.0%、2.5%、3.0% 与止损幅度 1.0%、1.5%、2.0%、2.5%、3.0% 组成的25组参数进行对照。选择规则固定为：已完成交易不少于100笔、最大回撤不低于-30%的组合中，选择累计复利收益最高者；若无符合条件的组合，则不产生候选策略。
- 参数冻结后，仅对最终留出集评估一次所选组合，不使用最终留出集指标反向选择参数。完整网格、筛选门槛、选择结果和最终留出集结果写入复利研究JSON。
- 退出模拟新增跳空成交处理：触发止损时若开盘已低于止损价，按更差的开盘价计；触发止盈时若开盘高于目标价，按开盘价计。T+1不退出、T+2起退出以及同日止盈止损冲突时止损优先保持不变。
- 所有结果继续标记为仅供研究；即使命中率较高，也不得绕过净复利、回撤、样本量和逐年稳定性门槛直接发布正式模型。


## 2026-10-10 入场概率阈值敏感性实验

- 第一轮退出规则网格未在验证集找到正复利方案，因此继续以固定基线退出规则开展入场阈值敏感性实验，避免同时调整入场与退出两个变量。
- 候选概率阈值为0.55、0.60、0.65、0.70、0.75、0.80；止盈目标与止损幅度固定为原基线值。仅在验证集选择阈值，要求完成交易不少于100笔且最大回撤不低于-30%。
- 如果满足样本量和回撤约束的候选中没有正复利方案，结果仅标记为研究对照，不视为可上线策略；如果没有候选满足风险门槛，则不选阈值。最终留出集只评估验证集冻结后的一个阈值，不参与选择。
- 每个阈值的交易数、累计复利、年化复利、最大回撤、夏普、命中率和退出原因均写入研究结果，生产策略保持不变。

### 因子扩展范围

可配置训练目录覆盖短中期收益、隔夜收益、成交量和成交额变化、5/10/20/60日均线位置及斜率、20/60日高点突破、K线实体和影线、波动率与下行波动、回撤、布林带、ATR、RSI、MACD、KDJ、涨停行为，以及市场上涨广度、中位涨跌幅、收益离散度、站上均线比例和正收益股票比例。

当前历史日线资产没有可靠、逐日可回溯的完整财务报表、估值快照、资金流或新闻情绪字段，因此本轮不伪造这类训练特征。只有接入时间点正确、可追溯的公开历史数据后，才将其加入训练。

所有技术因子必须只使用信号日T收盘及其以前的数据。继续遵守T+1开盘买入、T+2起最早退出、交易成本与涨跌停可交易性约束；训练集发现条件、验证集选择参数、最终留出集独立检验。命中率不能代替扣成本后的实际组合盈利能力。


### 2026-10-10 技术因子计算与断点兼容

### 标签时序修正：高收益路径必须可以在T+2起兑现

进一步检查发现，高收益路径模型原先将T+1盘中触及止盈目标视为正样本，与A股T+1持有约束不一致。本轮修正为只在T+2至最大持有期内评估止盈、止损路径，同时让“最高可兑现收益”指标也只计算可退出交易日。正式策略评分研究改用短线净收益标签函数，避免用高收益模型标签评估1%目标。新增云端测试分别验证T+1不计入、T+2及以后可计入的边界。
