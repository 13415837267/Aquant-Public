# 每日候选数量对照研究

## 研究问题

本研究比较每日最多入选1只（Top1）与最多入选2只（Top2）时，哪一种候选数量更能兼顾成本后收益、回撤与交易样本。当前正式策略仍处于研究/模拟状态，不因本实验修改候选准入规则或自动下单状态。

## 本轮新增：候选数量分别选参

- 使用同一个路径感知模型及相同可执行候选排序。
- Top1和Top2各自在2023—2024验证期独立扫描相同的入场概率阈值、净止盈目标与止损网格。
- 参数只有在验证期至少100笔完成交易、组合复利为正、年化复利为正、平均单笔净收益为正且最大回撤不差于-15%时才允许入选；如无参数达标，就明确报告无合格方案。
- 两种候选数量各自冻结自己的验证期入选参数，再分别评估2025—2026年9月历史补充期。
- 对每个入选点另外报告只改变一个参数、且相差一个网格步长的相邻参数结果，避免只报告单一峰值。
- 补充期已经被以往研究查看，不能称为全新未见留出集，也不参与参数选择。网格仍有多重比较偏差；相邻参数敏感性通过后，仍须进行更高成本压力测试与至少60个交易日的未来影子模拟。

## 交易执行与边界

两组统一采用T日收盘产生信号、T+1开盘模拟入场、T+2起允许退出、最长持有5个交易日、同日线同时触及止盈和止损时止损优先、往返交易成本10基点、无杠杆现金约束及相同的停牌/涨停执行门禁。

本实验只写入研究产物，不更新 Aquant-Private/main，不改变 data/candidates.json 的准入规则，不改变系统版本或发布门槛，也不启用自动下单。


## 下一轮优化：盈利因子门槛与成本压力测试（2026-10-16）

### 本轮目标

前一轮候选数量研究要求最少交易数、正复利、正年化复利、正平均单笔净收益和可接受回撤，但没有把项目正式晋级规则中的盈利因子下限落实到选参步骤。本轮补齐这一工程缺口，并对验证期冻结的参数增加交易成本压力测试。

### 新的选参与复核规则

- 盈利因子定义为成本后正收益交易净收益之和除以成本后负收益交易净亏损绝对值之和；没有亏损交易时盈利因子记为未定义，不把它自动视为通过。
- Top1与Top2继续各自独立选择验证期参数。除了原有门槛，验证期盈利因子必须不低于配置中的1.2；若不存在合格组合，明确报告无合格操作点，不降低标准。
- 验证期选出的参数冻结后，在原往返成本基础上分别按配置倍率1.5倍及2倍复核。压力结果只用于否决与稳健性判断，不用于重新选参。
- 补充输出完整冻结参数的年度复利分布，以及验证期、补充期与成本压力情境的盈利因子。成本压力情景还需同时报告复利、最大回撤、平均单笔净收益与交易数。
- 通用回测器增加可配置成本覆盖入口，默认参数和既有研究仍使用配置的基础交易成本，不改变原有默认口径。

### 决策边界

历史补充期已在此前研究中被查看，仍然不是全新独立留出集；盈利因子和成本压力只增加历史否决证据。所有结果必须经过 GitHub 云端语法检查、全量测试与本轮回测工件核验。无论结果如何，本轮不修改正式生产模型、候选池、策略版本或自动下单状态。

## 第二轮：将交易成本稳健性纳入参数选择（2026-10-16）

### 实验设计

上一轮只依据基准成本下的验证期复利挑选操作点，随后才在历史补充期做成本压力复核。第二轮保持训练样本、候选排序、时间切分和交易执行规则不变，只改变参数选择规则，防止一个只在低成本假设下表现好的参数成为首选。

- 每个候选数量继续独立扫描原有阈值、净止盈与止损参数网格。
- 对每组参数，在验证期分别按基准往返成本、配置的1.5倍和2倍成本计算交易结果。
- 同一参数必须在全部成本场景下同时满足：至少100笔完成交易、复利为正、年化复利为正、平均单笔净收益为正、盈利因子不低于1.2、最大回撤不差于-15%。门槛不因无合格组合而放宽。
- 对全部成本场景都合格的参数，优先比较最高配置成本下的复利，再比较较低成本下的复利、最高成本回撤和最弱盈利因子；这是唯一新增的选参规则。
- 冻结入选参数后，再计算历史补充期与成本压力结果。补充期此前已被查看，只用于辅助审查，不参加参数选择，也不作为真正未见留出集。
- 同时保留旧规则的基准成本最优结果作为对照。该实验不会更改正式版本、生产候选池或自动下单状态。

### 判定

实验是否成功，以 GitHub 云端质量检查、全量测试、研究工件中的参数与各成本结果为准。若无操作点在全部成本场景下同时合格，结果必须为“无合格成本稳健操作点”，不得用历史补充期反向挑参。


## 第三轮：在冻结的Top2参数上检验市场广度过滤（2026-10-16）

### 实验目的

在成本稳健选参确认Top2为优先研究方案后，下一轮不再同时修改模型阈值、止盈、止损或每日候选数量，只检验信号日市场上涨广度门槛是否能改善执行组合。市场广度在T日收盘即可计算，因此可用于T日信号门禁，不读取未来价格路径。

### 实验方法

- 将第二轮选出的Top2成本稳健参数完整冻结；候选模型、概率阈值、净止盈、止损、Top2上限、现金约束、交易时序与价格路径均不变。
- 对照无市场过滤基准，以及配置已有的市场广度下限（40%、45%、50%、55%、60%、65%）。当T日市场上涨广度低于门槛时，当日不入场；不补足候选、不更换排序。
- 每个门槛在验证期分别评估基准往返成本、1.5倍与2倍成本。最低100笔完成交易、正复利、正年化复利、正平均单笔净收益、盈利因子不低于1.2及最大回撤不差于-15%必须在三种成本下全部满足。
- 只按验证期成本结果选中门槛；排序优先比较2倍成本下复利，再比较1.5倍及基准成本表现、最高成本回撤与最弱盈利因子。若无过滤基准胜出，结论为保留现有方案、不增加市场过滤；如果没有任何门槛合格，则明确拒绝。
- 选定门槛后，仅将该冻结门槛与无过滤基准放到历史补充期做比较，并保留10、15、20基点三种成本口径。补充期此前已被研究查看，不参与门槛选择，也不视为真正未见留出。
- 市场广度按信号日当日可见的主板股票横截面计算。任何日期缺少或出现非法市场广度时研究应直接失败，而不是静默放行。
- 本轮只生成研究报告，不改变正式模型、生产候选池、系统版本、发布门禁或自动下单状态。
