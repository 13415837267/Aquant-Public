## 2. 模型生命周期

生产日常不重新训练。

### 新交易日

02 增量更新数据 → 读取固定模型 → 只使用信号日及此前可见数据 → 模型推理 → 生成候选 → 生成下一交易日计划 → 网页部署。

### 历史日期

读取同一固定模型 → 输入数据截断到目标信号日 → 禁止读取未来行情 → 输出历史截面候选。

### 新模型

只有新的研究模型完成验证并正式发布后，才允许重新训练、物化和替换生产模型资产。

最近完成的“07 可执行净收益研究”云端运行（运行编号 38260227351）未通过晋级门槛：

- 验证期（2023-01-03 至 2024-12-24）：验证期选出的“预测净收益为正才入场”方案复利收益为 -17.85%，最大回撤 -23.95%，严格目标命中率 57.83%；同期简单分类每日 Top1 基准复利收益为 -15.42%，命中率 58.87%。
- 补充检验期（2025-01-02 至 2026-09-30）：验证期选定的净收益回归方案复利收益为 +6.34%，最大回撤 -6.49%，严格目标命中率 66.83%；每日 Top1 分类基准复利收益为 +12.97%，命中率 67.30%。
- 结论：拒绝当前净收益回归方案晋级。它在验证期为负收益，在补充检验期也弱于简单分类基准；两个区间的严格目标命中率均未达到 80%。

2025-01 至 2026-09 的历史补充检验期已经被其他研究反复分析，不能作为全项目层面从未查看过的独立留出集。后续不再用该区间反复挑选参数，也不以增加训练轮数作为进展指标。

下一阶段应在完全一致的交易执行、成本、资金与 TopN 约束下，对照已冻结的可解释规则和简单分类基准；比较净复利、最大回撤、严格目标命中率、交易数量及分年度稳定性。只有在未参与调参的新前瞻模拟中持续满足晋级门槛，才评估是否更改生产模型。当前正式模型、候选规则与自动下单状态均保持不变。


### 上涨样本归因补充证据

云端运行 38215044099 使用 2015-01-05 至 2026-10-09 的历史行情，仅做事后标签与因子差异分析，没有训练模型、搜索阈值或修改生产策略。

- 对可执行入场样本，净收益目标 +3% 的命中率在发现期、验证期、补充检验期分别为 42.53%、38.56%、40.44%；+5% 目标分别为 29.89%、25.29%、26.46%；+8% 目标分别为 17.84%、14.26%、14.92%。
- 以 +5% 目标为例，ATR 因子的标准化均值差在发现期、验证期、补充检验期分别为 0.329、0.452、0.383；日内振幅对应为 0.293、0.349、0.329，方向一致。但这是事后命中样本的相关性，不等于因子筛选策略已经可盈利。
- +3%、+5% 和 +8% 目标的验证期平均实际净收益分别为 -0.169%、-0.110%、-0.037%，仅提高目标幅度或选择波动较大的股票并没有形成充分的可执行优势。

下一阶段的候选实验应围绕 ATR/振幅、隔夜收益和市场广度等单因子逐项做组合消融；保持当前生产目标和交易规则不变，所有因子方向必须先在发现期提出，再以验证期与同口径 Top1/Top2 基线比较。不得把本次事后因子差异直接写入生产候选规则。

## 10. 单因子匹配消融结果（云端运行 38324844385，2026-10-13）

### 实验设计

- 目标因子：市场广度；训练期冻结规则为 atr_14_pct<=0.4 AND market_breadth_pct>=65。
- 消融对照：保留控制条件 atr_14_pct<=0.4，分别比较加入和移除 market_breadth_pct>=65。
- 训练期该双条件共有 367,482 个样本，严格净 +1% 路径命中率为 63.06%，Wilson 下界为 62.90%。阈值仅来自 2015—2022 训练期。
- 统一约束：T 日收盘信号、T+1 开盘入场、T+2 起允许退出、最长 5 个交易日、净目标 +1%、止损 -3%、往返成本 10 bps、每日 Top2、现金约束不加杠杆。

### 验证期结果

| 指标 | 移除市场广度过滤 | 保留市场广度过滤 |
| --- | ---: | ---: |
| 组合复利 | +2.9006% | +4.2241% |
| 最大回撤 | -8.8452% | -2.7299% |
| 严格净 +1% 命中率 | 51.7045% | 54.0323% |
| 完成交易 | 704 | 248 |
| 期末未平仓 | 8 | 0 |

加入市场广度过滤后，复利提高 1.3235 个百分点、最大回撤改善 6.1153 个百分点、命中率提高 2.3278 个百分点；交易数明显减少。移除过滤的版本在验证窗口末仍有 8 笔未平仓，因此该期差异不能被直接视为独立因果证明。

### 历史补充期结果

| 指标 | 移除市场广度过滤 | 保留市场广度过滤 |
| --- | ---: | ---: |
| 组合复利 | -17.8960% | -1.7029% |
| 最大回撤 | -18.4665% | -2.3870% |
| 严格净 +1% 命中率 | 41.1137% | 41.4414% |
| 正收益交易率 | 52.6066% | 55.4054% |
| 完成交易 | 844 | 222 |

补充期复利差改善 16.1931 个百分点、最大回撤改善 16.0795 个百分点，但过滤版本依然亏损 1.7029%。该区间曾被此前研究查看，不是新的独立留出集；交易样本也大幅减少。

### 实验判定

- **保留为研究挑战因子，拒绝晋级生产。** 当前证据支持市场广度过滤可能降低不利行情下的交易频率与回撤，但仍未证明能跨周期稳定获得正收益。
- ATR/日内振幅与隔夜收益本轮均未形成符合预设匹配条件的训练期候选，因此被明确跳过；不能据此认定它们无效。下一次应扩大训练期候选覆盖，但仍不得使用验证期或补充期反向挑选条件。
- 正式模型 data/models/production_v1.json、阈值、候选池和自动下单状态保持不变。该实验结论仅属于研究资产。
