## 1. 唯一策略源与动态跟随规则

- 唯一策略源为个人私有仓库 `Aquant-Private/main`；公开仓库负责行情、候选生产、审计和网页构建。
- 每次候选工作流均重新检出 Private/main 当前最新提交，不把某一历史策略版本或提交 SHA 固定为长期运行前提。
- 策略版本号、提交 SHA、准入政策、因子权重及候选数量上限会按本轮私有策略自动同步。提交 SHA 只用于标识本轮候选、模拟计划和审计结果的实际来源，下一轮继续读取最新 main。
- 研究进度不是候选生成的阻断条件。当前策略即使尚未完成历史验证、成本压力测试或未来影子模拟，也会立即用于生成研究/模拟候选；策略提交变化时，旧验证证据不转移到新提交，研究状态重置为待验证。
- 候选生成必须真实调用当前 Private/main 策略，不得把旧模型、旧候选或历史实验结果改名冒充新快照。通过准入的标的可以为空；风险状态不合格或没有标的通过当前策略时允许空池。

## 2. 每日云端运行流程

每日北京时间18:05执行候选兜底检查；每日增量数据维护完成后也会检查。工作流先取得最新已落库交易日，再检出 Private/main 最新策略，按本轮策略同步元数据、生成并验证候选、生成下一交易日模拟计划、更新系统审计，最后由网页工作流构建部署。

非交易日或当日行情尚未完整落库时使用最近一个已落库的完整交易日数据，并明确标注数据截止日。手动回放指定历史日期时，只能使用仓库中确实存在的该交易日历史文件，不得悄悄替换成其他日期。

所有构建、验证、回测、测试与任务执行均在 GitHub 云端完成，不在本地运行验证。每次代码修改都必须同步更新中文文档，并使用中文提交说明。

## 3. 数据与交易时序硬约束

- 历史行情优先复用公开仓库现有数据；新增数据增量更新、校验、去重合并，具备断点恢复能力，不重复全量下载。
- 选股只能使用信号日收盘及此前可见的数据，禁止未来函数、数据穿越和未来标签泄漏。
- A股交易时序固定为：T日收盘产生信号，最早T+1开盘模拟买入，最早T+2及之后模拟卖出，最长持有5个完整交易日；禁止同日买入后卖出。
- 网页、候选快照与下一交易日计划只使用同一份当前候选产物，不允许网页维护第二套股票名单。

## 4. 研究候选与正式发布分离

- 当前 Private/main 策略产出的候选只标记为研究/模拟候选，不能冒充正式生产信号。
- 正式发布必须由独立的历史验证、组合执行约束、成本压力测试、参数稳健性、未来影子模拟与系统审计门禁共同决定。旧提交通过的研究证据不自动适用于更新后的策略提交。
- 即使正式发布门禁未来通过，自动下单仍保持关闭；本系统不会自动发送或执行券商订单。
- 系统版本清单与研究状态是每轮运行生成的来源记录，不是限制策略停留在某一旧版本的固定钉子。候选工作流若无法取得最新私有策略、无法验证版本来源或未通过风险/PIT校验，应失败关闭，不展示未经验证的候选。

## 5. 仓库与主要产物

### Aquant-Private

保存唯一策略源、策略参数、因子、候选准入政策和策略研究代码。

### Aquant-Public

- `data/candidates.json`：当前研究候选快照

- `app`：网页

旧近期训练窗口模型和固定版本模型仅保留为历史研究基准，不覆盖当前 Private/main 研究策略输出。

## 6. 工作流职责

- `01 Python质量检查`：云端语法检查和自动化测试。
- `02 数据维护`：交易日识别和历史行情增量维护。
- `03 候选池生产`：每次读取 Private/main 最新策略，生成研究候选与下一交易日计划。
- `05 网页自动部署`：根据当前活动快照和状态文件重建网页。
- 其他训练、回测、因子分析和影子研究工作流只更新研究资产；研究尚未完成不阻断当前策略的研究候选展示。

## 7. 当前禁止事项

- 禁止把固定历史策略版本或旧提交 SHA 作为每日候选生成的长期前提。
- 禁止候选生成使用未来数据、错误数据截止日或与本次实际策略提交不一致的代码。
- 禁止同日买入后卖出；禁止绕过T+1/T+2及最长5日的交易时序约束。
- 禁止把研究候选标成正式发布，或因研究未完成而错误展示旧策略作为当前候选。
- 禁止自动下单；禁止网页创建第二套独立候选列表。
- 禁止在 Private 以外建立第二个策略源。
- 禁止在本地运行训练、生产验证或正式测试。

## 历史研究与晋级记录（截至2026-10-14）

以下内容记录当时的研究结论与实验决策。若其中关于固定模型或每日候选规则的描述与本文前述当前运行规则不同，以本文当前运行规则为准。

### 2026-10-13 研究晋级与当期方向

最近完成的“07 可执行净收益研究”云端运行（运行编号 38260227351）未通过晋级门槛：

- 验证期（2023-01-03 至 2024-12-24）：验证期选出的“预测净收益为正才入场”方案复利收益为 -17.85%，最大回撤 -23.95%，严格目标命中率 57.83%；同期简单分类每日 Top1 基准复利收益为 -15.42%，命中率 58.87%。
- 补充检验期（2025-01-02 至 2026-09-30）：验证期选定的净收益回归方案复利收益为 +6.34%，最大回撤 -6.49%，严格目标命中率 66.83%；每日 Top1 分类基准复利收益为 +12.97%，命中率 67.30%。
- 结论：拒绝当前净收益回归方案晋级。它在验证期为负收益，在补充检验期也弱于简单分类基准；两个区间的严格目标命中率均未达到 80%。

2025-01 至 2026-09 的历史补充检验期已经被其他研究反复分析，不能作为全项目层面从未查看过的独立留出集。后续不再用该区间反复挑选参数，也不以增加训练轮数作为进展指标。

下一阶段应在完全一致的交易执行、成本、资金与 TopN 约束下，对照已冻结的可解释规则和简单分类基准；比较净复利、最大回撤、严格目标命中率、交易数量及分年度稳定性。只有在未参与调参的新前瞻模拟中持续满足晋级门槛，才评估是否更改生产模型。当前正式模型、候选规则与自动下单状态均保持不变。


### 上涨样本归因补充证据

云端运行 38215044099 使用 2015-01-05 至 2026-10-09 的历史行情，仅做事后标签与因子差异分析，没有训练模型、搜索阈值或修改生产策略。

- 对可执行入场样本，净收益目标 +3% 的命中率在发现期、验证期、补充检验期分别为 42.53%、38.56%、40.44%；+5% 目标分别为 29.89%、25.29%、26.46%；+8% 目标分别为 17.84%、14.26%、14.92%。
- 以 +5% 目标为例，ATR 因子的标准化均值差在发现期、验证期、补充检验期分别为 0.329、0.452、0.383；日内振幅对应为 0.293、0.349、0.329，方向一致。但这是事后命中样本的相关性，不等于因子筛选策略已经可盈利。
- +3%、+5% 和 +8% 目标的验证期平均实际净收益分别为 -0.169%、-0.110%、-0.037%，仅提高目标幅度或选择波动较大的股票并没有形成充分的可执行优势。

下一阶段的候选实验应围绕 ATR/振幅、隔夜收益和市场广度等单因子逐项做组合消融；保持当前生产目标和交易规则不变，所有因子方向必须先在发现期提出，再以验证期与同口径 Top1/Top2 基线比较。不得把本次事后因子差异直接写入生产候选规则。

## 10. 单因子匹配消融结果（云端运行 38324844385，2026-10-13）

### 实验设计

- 目标因子：市场广度；训练期冻结规则为 atr_14_pct<=0.4 AND market_breadth_pct>=65。
- 消融对照：保留控制条件 atr_14_pct<=0.4，分别比较加入和移除 market_breadth_pct>=65。
- 训练期该双条件共有 367,482 个样本，严格净 +1% 路径命中率为 63.06%，Wilson 下界为 62.90%。阈值仅来自 2015—2022 训练期。
- 统一约束：T 日收盘信号、T+1 开盘入场、T+2 起允许退出、最长 5 个交易日、净目标 +1%、止损 -3%、往返成本 10 bps、每日 Top2、现金约束不加杠杆。

### 验证期结果

| --- | ---: | ---: |
| 组合复利 | +2.9006% | +4.2241% |
| 最大回撤 | -8.8452% | -2.7299% |
| 严格净 +1% 命中率 | 51.7045% | 54.0323% |
| 完成交易 | 704 | 248 |
| 期末未平仓 | 8 | 0 |

加入市场广度过滤后，复利提高 1.3235 个百分点、最大回撤改善 6.1153 个百分点、命中率提高 2.3278 个百分点；交易数明显减少。移除过滤的版本在验证窗口末仍有 8 笔未平仓，因此该期差异不能被直接视为独立因果证明。

### 实验判定

- **保留为研究挑战因子，拒绝晋级生产。** 当前证据支持市场广度过滤可能降低不利行情下的交易频率与回撤，但仍未证明能跨周期稳定获得正收益。
- ATR/日内振幅与隔夜收益本轮均未形成符合预设匹配条件的训练期候选，因此被明确跳过；不能据此认定它们无效。下一次应扩大训练期候选覆盖，但仍不得使用验证期或补充期反向挑选条件。
- 正式模型 data/models/production_v1.json、阈值、候选池和自动下单状态保持不变。该实验结论仅属于研究资产。

## 12. 可执行净收益训练标签一致性修复（2026-10-14）

- 核查发现：净收益回归训练标签此前仅按未来价格路径计算收益，没有应用组合回测使用的T+1开盘可执行门禁；这会把开盘涨停、停牌或涨停价缺失的不可执行样本纳入训练，造成训练目标与实际候选执行规则不一致。
- 修复：训练标签生成现在复用统一的 `executable_entry_mask`，只有符合T+1开盘可执行条件的样本才参与净收益回归训练；不可执行样本不会被赋予虚构的可交易收益。
- 验证：新增自动化测试，覆盖开盘涨停样本被排除、普通可执行样本保留。代码、测试及文档一并提交；云端质量与净收益研究运行完成前，不宣称修复已经通过验证。
- 研究边界：只修正训练标签与交易执行规则的一致性，不修改正式生产模型、每日候选生成方式或自动下单状态。后续以同口径验证期真实组合净收益、严格净+1%命中率、最大回撤及交易样本量决定是否保留。
