# Contributing

## Required maintenance record

Every code change must update `CHANGELOG.md` in the same pull request. Data-only refreshes are generated by the scheduled pipeline and recorded in Git history with a `data:` commit.

## Commit style

Use focused messages:

- `strategy: ...`
- `ui: ...`
- `data: ...`
- `ops: ...`
- `docs: ...`

## Release flow

1. Research and iterate in `Aquant-Private`.
2. Bump the strategy version and changelog there.
3. Publish only release-safe runtime changes into `Aquant-Public`.
4. Verify GitHub Actions tests before merging.
