# 外部策略历史评估模块

## 目的与边界

本目录独立评估此前搜索到的公开策略，**只生成研究报告，不接入正式候选池、不修改正式模型、不触发下单**。所有完整历史计算由 GitHub Actions 云端执行；复用仓库现存的 `data/history` 行情文件与 `scripts/short_term_research.py` 日线特征，不重复下载历史数据。

## 当前可执行策略

| 模块内标识 | 公开来源 | 复现口径 | 注意事项 |
| --- | --- | --- | --- |
| `public_picker_approx` | [online0001/short-term-stock-picker](https://github.com/online0001/short-term-stock-picker) | 按公开说明复现均线多头、近期涨停、换手率、量能约束及排序评分 | 现有日线数据不含完整流通市值字段，属于近似复现，不代表原项目逐行复现 |
| `khunter_pullback_proxy` | [ling-0729/KHunter](https://github.com/ling-0729/KHunter) | 以均线趋势、回撤、缩量和换手率构造可检验的趋势回调代理规则 | 原项目具体参数与数据接口未完全对齐，明确标注为代理规则 |
| `momentum20_baseline` | [whilefog233/MiniQuantLab](https://github.com/whilefog233/MiniQuantLab)；[LiangRan2003/china-momentum-strategy](https://github.com/LiangRan2003/china-momentum-strategy) | 以20日动量、均线趋势及波动率调整做可复现基线 | 仅为日线多头对照，不等于原项目的多空/时序动量完整实现 |

参数集中在本目录的 `config.json`。未经事先冻结的参数不可按最终补充期表现反向调优。

## 暂不可公平复现的搜索结果

- **KHunter 龙头打板**：原策略依赖涨停列表、封板时间等字段；仅凭现有日线不能可靠复现封板时刻，也不能把该字段推测出来。
- **Transformer-alpha-factor-Chinese**：仓库公开摘要与回测报告的收益口径不一致，原报告只有34个交易日；须先核对原始模型、输入因子、数据版本和评估脚本，不能将作者披露的年化值当作本模块实测结果。
- **三维选股系统**：所需的资金流和板块热度无法由当前统一日线文件完整构造。
- **quant-dashboard**：公开输出存在多个时段、不同策略与不同总收益口径，缺少统一、可审计的A股日线输入与组合定义，不直接纳入排名。

上述限制会随每次报告输出，不会用“近似收益”冒充原仓库实证结果。

## 统一回测约束

- 信号只使用 T 日收盘以及此前已经可见的数据。
- 最早在 T+1 开盘入场；买入当日禁止退出，最早 T+2 退出。
- 主板股票范围复用现有历史研究的数据清洗与可交易性检查；开盘涨停、停牌或缺少必要价格的标的不作为可执行入场。
- 每个策略最多持有配置指定数量的同时持仓；以资金余额和持仓槽位约束买入规模。
- 沿用系统当前研究配置的止盈、止损、最长持有交易日与交易成本口径；同日同时触及止盈和止损时，按止损优先的保守规则处理。
- 报告总收益、年化复利、最大回撤、夏普、交易数、严格净收益目标胜率、候选覆盖率及区间末未平仓数。
- 研究按开发期、验证期和历史补充期分别报告。历史补充期已在项目其他研究中被查看，不能宣称是从未触碰的独立留出集。

## 在 GitHub 云端运行

进入公开仓库的 **Actions →「12 外部策略历史评估」→ Run workflow**，选择完整区间或单个区间。流程先执行质量检查，再运行历史回测；报告以工作流工件保存，不写入正式候选快照，不触发网页部署。

结果文件：`data/backtest/external_strategy_evaluation_latest.json`。

本地设备不作为项目运行或验证环境。
