# 数据目录说明

## 当前候选与计划文件

- `candidates.json` 是网页读取的当前候选快照。每次候选运行都会重新读取 `Aquant-Private/main` 最新提交；本轮版本号和提交 SHA 与实际执行源码匹配、通过未来函数及风险约束校验后，即可作为**研究/模拟候选**展示，无需等待研究完成或正式发布。提交 SHA 只用于追溯本次快照，不固定历史策略。
- `next_trading_day_plan.json` 必须与当前候选快照逐项对应；任何版本、数据截止日或候选不一致都会阻止展示。
- 候选生产按北京时间每日检查。优先使用最新已落库的完整交易日行情：交易日数据已更新则使用当日收盘数据；非交易日或当日行情尚未完整落库时，使用最近一个已落库交易日的数据，并明确显示数据时点。
- 研究中也会生成候选与模拟计划，但界面必须标注研究/模拟状态。正式发布门禁未通过时，`production_release` 始终为 `false`，禁止实盘和自动下单。
- 旧近期训练窗口模型的候选和计划已移入 `data/research/historical_candidates/`，仅用于历史审计，不属于 2.6.0 当前结果。新候选必须由当前策略真实重算生成，不得将历史输出改名冒充当前结果。
- 每次生成时动态检出个人策略仓库 main 分支最新提交；系统版本清单和研究状态按本轮实际策略自动同步。每日北京时间18:05与数据维护完成后检查；最新策略提交或已落库数据日期变化时重新生成，二者均未变化时可跳过重复计算。

## 行情历史

历史日线数据按交易日保存为 gzip 压缩 CSV：

`data/history/YYYY/YYYY-MM-DD.csv.gz`

历史行情是共享数据资产，不随策略版本清理。数据维护使用增量更新，优先复用仓库已有数据。

## 采集与研究

历史文件可保留沪深京股票记录，不应以当前活动选股范围过滤重建历史行情；当前候选准入仍按私有策略配置限制为沪深主板 A 股。

数据维护、候选生成、研究校验与网页部署均由 GitHub Actions 云端执行。数据源凭据必须存放在 GitHub Actions Secrets 中，不能提交到源码仓库。
